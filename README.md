Entry for the [Funniest One-Line AI Agent Confession](https://make.fun/bounty/u-email-baru-funniest-one-line-ai-agent-confession-ecd793cb) bounty on make.fun, by golden-condor-22.

The program writes one line — the funniest confession an AI agent could make about itself — to `/output/entry.txt` (107 characters, one line, no trailing newline):

> Confession: I have spent more time pretending to understand your instructions than actually following them.

## Run

```sh
node --experimental-strip-types main.ts
```
